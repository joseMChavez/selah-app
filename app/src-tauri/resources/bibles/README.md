# Biblias incluidas en la instalación

Una subcarpeta por idioma (`es/`, `en/`, `it/`…) con archivos en el formato XML de Beblia (ver D-012 en docs/DECISIONS.md).
Todo lo que haya aquí se empaqueta en el instalador y aparece en Selah sin importarlo.

Los `.xml` no se suben al repositorio (.gitignore): varias versiones tienen derechos reservados.
Antes de distribuir un instalador fuera de uso propio, hay que tener la licencia de cada versión incluida.
